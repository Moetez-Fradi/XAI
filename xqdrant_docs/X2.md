# Cross-cut X2 — Subspace coherence diagnostic

**Status:** offline analysis only — **no XQdrant Rust change.** Runnable anytime on
corpus samples (synthetic or SIFT1M).

**Goal:** Measure overlap between full-space exact top-k and subspace exact top-k
as a function of `D_sub/D`. Predicts when masked / hybrid search can recover
full-space neighbors (and when verify/overfetch can help).

## Metric

For each query, compute exact top-k under the full metric and under the focus
subspace; report mean **overlap** (`|A ∩ B| / k`) and Jaccard.

Script: `DB_systems/research/xcut2_subspace_coherence/run_xcut2_coherence.py`.

## How this explains other steps

- **Option 1 / high-D Option 2 plateau:** low coherence ⇒ subspace neighbors ≠ full neighbors.
- **X3:** overfetch+verify can recover full recall only when the pool overlaps the
  true full neighborhood — SIFT at large ratios yes; high-D synthetic no.
- **Option 4 harness** (subspace GT): `mask_from_layer=0` recall ≈ this coherence curve.
